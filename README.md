# HDFC Flexi Cap Fund — ₹2,000 Monthly SIP Power BI Dashboard

Financial Analytics / Investment Analytics portfolio project built in Microsoft Power BI.

## Project
This dashboard models a **₹2,000 monthly SIP** in HDFC Flexi Cap Fund from **January 1995 to September 2026** using historical NAV data.

### Dashboard pages
1. Overview
2. SIP Analysis — dedicated ₹2,000 monthly SIP analysis
3. Performance
4. Fund Vs Benchmark
5. Portfolio & Holdings
6. Risk Analysis
7. Fund Manager
8. Historical NAV
9. Key Takeaways

### SIP Analysis
The dedicated SIP page answers: *If ₹2,000 were invested every month, what was invested, how many units were accumulated, and what is the modeled value?*

### Important methodology
Monthly units = Investment ÷ NAV.

Current modeled value = Total SIP Units × latest Regular Growth NAV.

SIP XIRR uses monthly cash flows and a final valuation on **10-Sep-2026**.

This is an analytical illustration, not an actual investor account statement. Historical results do not guarantee future returns.
